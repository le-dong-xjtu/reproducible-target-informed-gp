# Essay evidence package

This directory freezes the data, figures, and scripts used for the revised
nine-page IEEE-style paper.

- `data/` contains archived earlier benchmarks and derived summaries. The current matched global-surrogate comparison is stored under `../results/coil_2d_relative_tolerance/surrogate_family_comparison_budget27/`.
- `figures/` contains publication-ready PNG, SVG, and vector PDF versions. Captions and statistical definitions are in `figures/captions.md` rather than embedded as plot titles or footnotes.
- `scripts/render_figures.py` recreates Figs. 1--4;
  `scripts/render_automated_stopping.py` recreates Fig. 5; and
  `scripts/render_wpt_selected_geometry.py` recreates Fig. 6.
- `coil_surrogate_ieee_draft.tex` and its compiled PDF are authoritative.
  `manuscript_partial.md` is an older convenience snapshot and must not be
  cited for the current mixed-acquisition results.
- `author.yaml` stores the default author identity and official English affiliation for future editing sessions.
- `proposed_algorithm.md` archives the exploratory TC-FEI study; it is not presented as the paper's proposed method.
- `gp_error_analysis.md` decomposes the B=27 GP's regression, calibration, candidate-recall, and decision-pool errors from raw ten-seed evidence.
- `tcfei_literature_positioning.md` records the focused prior-art search and limits the novelty claim.
- `wpt_source_scope.md` records the exact 14-to-8 variable interpretation of
  the source PDF and why the older tolerance artifacts are excluded.
- `sources/elp2.70015.pdf` is a checksum-identical local copy of the WPT source
  passage used for the 8-D formulation.
- `evidence_manifest.md` maps every empirical figure, table, and numerical
  claim to its exact generating script and retained raw data.
- `data/tcfei_budget27_results_10seeds.csv` and `data/tcfei_budget27_summary.json` archive the exploratory TC-FEI evaluation; they are not used for the current main claim.
- `../results/coil_2d_relative_tolerance/cei_budget27/`, `standard_bo_budget27/`, and `global_dual_gp_budget27/` contain the matched 870-case GP-cEI, GP-cLCB, GP-IVR, and balanced global dual-response benchmarks used in Fig. 4. Each contains raw results and a machine-readable summary.
- `data/center_feasibility_smoke/` contains the ten-target screen that selects the working 75/25
  feasibility/inductance-uncertainty rule. `data/center_feasibility_low_targets/`
  contains the explicitly post-hoc diagnostic on the random-six baseline's
  four low-inductance targets. Both directories retain raw rows, summaries, and
  manifests, with generating code under `scripts/run_center_*.py`.
- `data/center_cosine_stopping_smoke/`, `data/center_stopping_1pct_smoke/`,
  and `data/center_stopping_1pct_deterministic_gp_k5/` contain the matched
  stopping-threshold and GP-reproducibility screen. The main configuration is
  ordinary cEI, a 1% threshold for three refits, deterministic $K=5$ GP
  multistart, and ten confirmations. The cosine policy is retained only as a
  negative development control.
- `data/center_stopping_heldout_73/` contains the independent test on every
  lattice target excluded from the 14-target development set. It is generated
  by `scripts/run_automatic_gp_2d.py` with all settings frozen.
- `data/stopping_gp_calibration_heldout_73/` evaluates both target-conditioned
  posteriors exactly at those 73 stopping points, before confirmations. It is
  generated by `scripts/analyze_stopping_gp_calibration.py`.
- `../results/coil_2d_relative_tolerance/surrogate_family_comparison_budget27/` contains the 3,480-case GP/ten-NN × random/uncertainty-selection comparison used in Fig. 1.
- `../results/coil_2d_relative_tolerance/cei_neural_hybrid/` contains the
  earlier single-auxiliary confirmation retained as a component control.
- `../results/coil_2d_relative_tolerance/mixed_uncertainty/` contains the
  shared-sample four-signal weight screen and the nested $B=24$--30 budget
  audit.  Its budget identity is always $B=6+x+12$, where $x$ is the number of
  sequential acquisitions.
- `data/wpt_8d_mixed/` contains the nominal-alignment 8-D WPT benchmark at
  $B=6+32+12=50$.  The earlier tolerance-sweep files are retained as historical
  artifacts but are outside the revised paper's scope.
- `data/wpt_8d_automated_cei/` contains the deterministic 8-D transfer at
  $B=34+10=44$, including its complete active trace and a bitwise-identical
  replay of all selected designs. `data/wpt_8d_automated_cei_fixed_b50_control/`
  is the matched forced-continuation control; it returns the same decision at
  $B=40+10=50$.
- `data/wpt_8d_multitarget_validation/` contains the frozen 21-target matched WPT
  comparison among automatic cEI, conventional six-point cEI, one-center
  pure-feasibility-then-cEI, and nonadaptive Sobol search, together with both
  fixed-$B=50$ GP controls and runtime splits. It is generated by
  `scripts/run_wpt_8d_multitarget_validation.py`.
- `data/confirmation_count_ablation/` contains the development-only replay of
  0, 1, 2, 5, and 10 prefixes of the stored confirmation rankings, generated
  by `scripts/analyze_confirmation_ablation.py`.
- `data/initialization_screen_1000/` contains the prespecified 1,000-seed,
  87-target random-six initialization screen.  It is a pre-optimization
  coverage diagnostic, not an end-to-end GP-cEI result.  The archived point
  table, raw 87,000 rows, summary, and independent verifier are retained.
  `initialization_stress_test_protocol.md` freezes the stronger end-to-end
  experiment but does not claim that it has been executed.
  `scripts/run_worst_initialization_case.py` injects the preselected worst
  six-point design into the original full GP-cEI trajectory.  Both it and the
  deterministic workflow recover the exact 2-mH optimum; the latter uses 23
  rather than 27 calls, so this single case supports efficiency but not a
  final-quality superiority claim.
- `data/random6_adaptive_stopping/` is the matched operational start-policy
  comparison over ten seeds and all 87 targets. Random-six and center-start
  policies share the 75/25 discovery score, deterministic K=5 GP fitting,
  adaptive stop, confirmations, and maximum budget; their different initial
  sample counts necessarily reallocate active calls.
- `data/clcb_correct_sign_replay/` is a fresh 870-case replay produced by
  `scripts/verify_clcb_replay.py`; it confirms that the corrected cLCB equation
  reproduces every archived Fig. 4 decision and loss exactly.
- `aedt_validation/` and its older ZIP archives are historical, disconnected
  handoff artifacts and remain excluded.  The reported direct Maxwell evidence
  is instead frozen under `data/aedt_wpt_1000_matched/`: the complete automatic
  and Sobol-6+cEI-14 packages contain source, ledgers, confirmation plans, logs,
  and summaries, while the automatic package also contains the selected AEDT
  project.  `scripts/audit_aedt_wpt_matched.py` independently checks every
  number in the manuscript's matched 1000-nH table and its mesh caveat.
- `data/wpt_8d_budget_sweep_b30_b80/` contains the matched ten-seed cEI versus
  5%-per-source mixture sweep at every integer budget from 30 through 80. Its
  $B=50$ rows exactly replay the standalone result.
- `data/wpt_8d_sigma_mixture*/` contains the alternative experiment that
  replaces GP standard deviations inside probability of feasibility and EI
  with quantile-calibrated GP/disagreement/NTK mixtures. The audit and
  supplementary Fig. 8 are produced by
  `scripts/analyze_wpt_8d_sigma_mixture.py`.
- `data/wpt_8d_sequential_dual_confirmation/` tests one-at-a-time terminal
  selection by cEI and effective sigma, including alternating and gated 6/6
  schedules. Its audit is
  `scripts/analyze_wpt_8d_sequential_dual_confirmation.py`.
- `data/wpt_8d_average_acquisition_diversity/` tests the 50/50 average of
  pure cEI and effective-sigma cEI throughout active selection, followed by
  original, softly penalized, and hard-minimum-separation confirmation rules.
- `full_manuscript_verification_report.md` is a clearly labelled historical
  audit of the superseded B=20/B=27 and 14-D draft; it is not evidence for the
  revised mixed-acquisition and WPT claims.
- `independent_review_agy.md` records the independent review findings and corrections applied to the earlier draft.

Run from the repository root:

```sh
python3 essay/scripts/render_figures.py
python3 essay/scripts/render_automated_stopping.py
python3 essay/scripts/render_wpt_selected_geometry.py
python3 essay/scripts/render_wpt_budget_sweep.py
python3 essay/scripts/run_automatic_gp_2d.py
python3 essay/scripts/analyze_stopping_gp_calibration.py
python3 essay/scripts/analyze_confirmation_ablation.py
python3 essay/scripts/verify_initialization_screen.py
python3 essay/scripts/run_wpt_8d_multitarget_validation.py
python3 essay/scripts/verify_clcb_replay.py
python3 essay/scripts/audit_aedt_wpt_matched.py
python3 essay/scripts/audit_revised_manuscript.py
```

The nine-page IEEE PDF can be rebuilt from `essay/` with:

```sh
latexmk -xelatex -interaction=nonstopmode -halt-on-error coil_surrogate_ieee_draft.tex
```

The benchmark domain has 1,110 admissible coil designs. All results use integer target inductances from 1 to 87 mH and the shared relative tolerance \(|L-L_t|/L_t\leq0.025\). The reference resistance is the exhaustive-search minimum among feasible designs.
